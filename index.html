No install script runs on this page — you run it locally, on your own machine.

OS

Windows 10 or 11. Reads your screen and moves your mouse, so it can't run headless or in the cloud.

Runtime

Python 3.10+. The installer script grabs every package the bot needs on first run.

Accounts

Your own Discord bot application and a BIG Games developer app — both free, both covered below.

Getting it running

01

Download and unzip

Grab the ZIP above, extract it anywhere — a folder on your Desktop is fine.

02

Run run.bat

Double-click it. First launch installs everything automatically, then asks four setup questions in plain English.

03

Follow the full guide once

Creating your Discord bot and BIG Games app takes about ten minutes the first time. README.md in the repo walks through every click.

04

Authorize and go

Type /authorize in Discord, approve access, and the status window on your desktop takes it from there.
